# Stretto 0.1.0 alpha 1 — first public preview

Stretto is a Windows download manager with resumable transfers, adaptive
connections, queues and browser integration. Part of Plexus Apps, built by
Marek Codex. Less babysitting the progress bar. That is the plan, anyway.

This is an **alpha for testing**, not the finished Store release.

## Download

`Stretto-0.1.0.0-win-x64-setup.unsigned.exe` is the per-user installer for
Windows x64, Windows 10 1809 or later. It includes the required .NET and Windows
App SDK runtime files. You do not need Visual Studio or the .NET SDK to use it.

The installer is **unsigned**. Windows may show an unknown-publisher or reputation
warning; this release does not claim a trusted signing identity. SHA-256 checksums
are provided separately. The Store app is still a draft, and no normally
installable signed MSIX is included in this preview.

## Included

- HTTP/HTTPS downloads with segmented transfers, restart/resume and retry handling.
- Queues, scheduling, speed limits, file organization and checksum checks.
- Bundled Chromium and Firefox browser extensions with a three-step setup wizard.
- Optional media extraction/conversion using separately installed ffmpeg or yt-dlp.

## Before you test

- Browser compatibility, final UI/accessibility acceptance and clean-machine
  installation, upgrade and uninstall checks are not complete. Report the exact
  app/extension, browser and Windows versions with a reproducible example.
- The Firefox XPI is unsigned. Regular Firefox supports a temporary installation
  through its debugging page; it disappears on restart. Other Firefox editions
  or forks may accept permanent unsigned installation depending on configuration.
- Some one-use links, form submissions and browser-bound authentication must stay
  in the browser. Stretto deliberately leaves POST and unknown-method capture alone.
- Media detection does not guarantee that a stream is supported or that you have
  permission to download it. Use content you are authorized to download.
- Optional video tools are not bundled. The standalone GitHub update channel is
  disabled in this alpha; future previews must be obtained manually.

The source build passed with zero warnings/errors. All 51 local engine tests and
the capture, media-detection and naming/handoff regression scripts passed. These
checks do not replace the acceptance work listed above.
