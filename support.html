A quick hand with Stretto.

Installing the preview

Use the EXE or MSIX instructions attached to the GitHub release. The first preview is still being prepared; an empty releases page means no public download is available yet. Test packages are self-signed, and development MSIX identities may require a separate installation when moving to the Store build.

Install one format at a time. EXE and MSIX have separate settings; switching is not an automatic migration. Export any history you want to retain. Never disable Windows protections to install a preview.

Connect the browser

Open Browser → Set up the extension inside Stretto. Chromium uses a bundled unpacked extension. Regular Firefox's unsigned temporary installation disappears on restart. Final marketplace distribution is pending.

Known limits

Some form submissions, one-use links and browser-bound sessions must remain in your browser. Media detection does not guarantee support. Optional ffmpeg and yt-dlp components are separate programs; only download content you are authorized to save.

Report a problem

Once the repository is public, open a GitHub issue with the app version, Windows/browser versions, expected behavior and reproduction steps. No guaranteed response time is offered.

Review reports before posting. URLs, cookies, tokens, logs, screenshots and paths can contain private information. Diagnostics are not automatically safe to publish.

For local help, press F1 or choose Help. Settings → Components & about → Troubleshooting provides logs and diagnostics.
